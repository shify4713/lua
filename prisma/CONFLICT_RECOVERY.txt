PRISMA — КАК УБРАТЬ МАРКЕРЫ КОНФЛИКТА GIT НА GITHUB
======================================================

Это служебные строки незавершённого слияния Git. Они не являются Lua-кодом.
В чистой версии PRISMA из архива таких строк нет.

Самый простой способ без команд:
1. Откройте https://github.com/shify4713/lua/tree/main/prisma
2. Удалите конфликтующую ветку/PR, если GitHub пишет «This branch has conflicts».
3. Создайте новую ветку от актуальной main.
4. Загрузите в неё СОДЕРЖИМОЕ чистой папки prisma из архива PRISMA.
5. Создайте новый Pull Request в main.

Если открыт редактор конфликтов GitHub:
1. Между строкой из семи знаков «<» и строкой из семи «=» — первый вариант.
2. Между строкой из семи знаков «=» и строкой из семи «>» — второй вариант.
3. Оставьте только полный вариант PRISMA 4.5.1.
4. Обязательно удалите сами три служебные строки.
5. Нажмите Mark as resolved, затем Commit merge.

Проверка после исправления:
поиск по репозиторию не должен находить строки, начинающиеся с
семи знаков «<» или семи знаков «>». Декоративная линия «=» допустима.

Установщик PRISMA 4.5.1 дополнительно проверяет скачанные Lua-файлы. Если
в них остались маркеры конфликта, он покажет «Git conflict markers» и НЕ
заменит старую рабочую копию повреждённым файлом.
