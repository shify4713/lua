PRISMA 4.5 — КАК РАССТАВИТЬ ADAPTER (OpenComputers 1.7.10)
================================================================

Каждый управляемый блок должен быть виден компьютеру как component.
Соедините все Adapter кабелем OpenComputers с главным компьютером.

РЕАКТОР DRACONIC EVOLUTION
--------------------------
1. Поставьте Adapter вплотную к Reactor Stabilizer (не к ядру).
2. В компонентной сети появится draconic_reactor.
3. Для каждого входного и выходного Flux Gate поставьте отдельный Adapter
   вплотную к гейту. Появятся компоненты flux_gate.
4. До авто-добавления поставьте на ВХОДНОМ гейте Low Flow = 100 RF/t.
   PRISMA использует это как метку входа щита. Надёжнее выбрать оба гейта
   вручную: ЭНЕРГИЯ -> Добавить -> Вручную.

Важно: в DE 1.7.10 override записывается методом setFlowOverride.
PRISMA включает override сама. Redstone-сигнал гейту не требуется.

ЭНЕРГОЯДРО
----------
1. Adapter вплотную к Energy Pylon/доступному блоку интеграции ядра:
   должен появиться draconic_rf_storage.
2. Ещё один Adapter вплотную к Flux Gate ядра.
3. Если свободных гейтов несколько, выберите гейт на вкладке ЭНЕРГИЯ.

ME И АВТОКРАФТ
---------------
1. Adapter вплотную к ME Interface/Controller, чтобы появился me_interface.
2. Inventory Controller НЕ НУЖЕН. Уберите его привязку из старых настроек.
3. Блочный ME Interface: задайте предмет в одном из 9 config-слотов шаблона
   и выберите «Из config-слота ME Interface».
4. Кабельный Part Interface требует сторону. Оставьте -1 (авто) или задайте
   0..5 в НАСТР. -> Общие -> Сторона кабельного ME.
5. Database Upgrade уровня 3 на скриншоте тоже поддерживается: заполненные
   записи доступны через «Из базы данных Adapter» (не более 81 ячейки).

Ограничение самого драйвера OpenComputers 1.7.10: me_interface предоставляет
getInterfaceConfiguration, то есть CONFIG-слоты. Физический буфер Interface
через этот компонент не опубликован. PRISMA не притворяется, что может его
прочитать, и не требует отсутствующий inventory_controller.

Полный список ME-сети PRISMA намеренно никогда не загружает: на больших
сетях это приводит к out of memory. Читаются только 9 config-слотов либо
небольшая Database Upgrade из Adapter.

РАДАР, ЧАТ, ОЧКИ
----------------
Поставьте Adapter рядом с соответствующим блоком. Затем откройте
НАСТР. -> Устройства и выберите найденный компонент, если авто-поиск
выбрал не тот. Поддерживаются альтернативные имена компонентов сенсоров.

ДИАГНОСТИКА
-----------
НАСТР. -> Система -> Сохранить диагностику создаёт файл:
  /home/prisma/data/diagnostics.txt
В нём есть имена и адреса всех компонентов, ошибки и нагрузка задач.
